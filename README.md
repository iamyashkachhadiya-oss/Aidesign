# LoomAI - Textile Design Studio

LoomAI is an AI-powered textile design web application for the Indian weaving market. The MVP focuses exclusively on the Toyota Rapier Loom with Dobby shedding configuration.

## Features

- **Machine Setup**: Input loom specs (reed width, shafts, color channels, etc.)
- **Design Input**: Describe your design or upload an image
- **AI-Powered Generation**: Receive 3 unique, physically weaveable designs
- **Constraint Engine**: Automatic validation for shafts, colors, floats, and width
- **Edit & Refine**: Adjust colors and refine patterns with AI instructions
- **Production Export**: Download designs as high-res PNGs with spec summary cards

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Constraint Engine**: Custom JavaScript logic for textile validation

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
